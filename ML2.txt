Machine learning lifecycle is a structured process that defines how machine learning models are developed,deployed and maintaianed.
It consists of a series of steps that ensure the model is accurate,reliable and scalable.


problem definition --> Data collection ---> Data cleaning & preprocessing --> Exploratory data analysis-->Feature Engineering & selection-->
-->model selection --> model training--> model Evaluation and tuning --> model deployment --> model monitoring & maintenance

It includes defining the problem ,collecting and preparing data exploring patterns engineering features,training and 
evaluating models,deploying them into  production and continously monitoring performance to 
handle issues like data drift and retraining neeeds.


1  Problem definintion 

The first step is identifying andf clearly defining the business problem A well framed problem 
provides the foundation for the entire life cycle .
Important things like project objectives desired outcomes and the scope of the task are carefully designed during this stage.
collabrate with stakeholders to understand business goals.
Define project objectives scope and success criteria
Ensure clarity in desired outcomes.


2. Data collection

Data collection phase invoves systematic collection of datasets that can be used as raw data to train model. 
The quality and variety of data directly affect the models performance.

Relevance : collected data should be relevant to defined problem and include necessary features.
Quality :  Ensure data quality by considering factors like accuracy and ethical use.
Quantity : gather sufficent  data volume to train a robust model.

Diversity :  Include diverse datasets to capture a broad range of scenarios and patterns.
